# Private photos

One photo per person, named by the person's `id` in the gitignored `src/data/deck.local.ts`, for example `nora.jpg` (`.jpg`, `.jpeg` or `.png`).

Everything in this folder except this file is in `.gitignore`, so family photos are never committed. A person without a photo here shows a neutral placeholder. The photos only travel from this computer's dev server to the phone over home Wi-Fi.
